# recursive-confabulation
Dataset and replication code for Recursive Confabulation: Measuring Model Accountability through Dual-Coder Agreement (κ = 0.83–1.0) — includes harm, elaboration, and blame IRR data with full reproducibility.

This repository contains:
- harm_irr.csv
- elaboration_irr.csv
- blame_irr.csv
- entity_taxonomy.csv
Each file includes final consensus codes after dual-review reconciliation (κ = 0.83–1.0).

Replication: Fisher tests and effect sizes are computed via `analysis.ipynb`.
